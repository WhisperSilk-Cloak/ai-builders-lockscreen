# AI Builders Lock Screen

A web countdown and Android live wallpaper for the AI Builders Challenge. Built for a Handshake mission.

## Web demo

Open the [live demo](https://whispersilk-cloak.github.io/ai-builders-lockscreen/) to choose a countdown, switch themes, and use Lock Screen View. The [signed Android APK](https://github.com/WhisperSilk-Cloak/ai-builders-lockscreen/releases/tag/v1.0.0) is available from GitHub Releases.

## Android

Open the `android` folder in Android Studio, let Gradle sync, and run the app on a device. Open the app and follow its prompts to set the live wallpaper.
